# Sachin Kumar Panchal - Portfolio

A cyberpunk OS-style portfolio built with the MERN stack. It includes a draggable desktop UI, 3D background, terminal app, and admin dashboard.

## Tech Stack

- Frontend: React, Vite, Framer Motion, Three.js
- Backend: Node.js, Express, MongoDB
- Auth: JWT
- Deployment: Vercel

## Live URLs

- Portfolio: https://sachin-portfolio-psi-six.vercel.app
- API: https://portfolio-api-gamma-five.vercel.app/api

## Local Setup

```bash
# backend
cd backend
npm install
npm run dev

# frontend
cd frontend
npm install
npm run dev
```

## Environment Variables

Backend `.env`

```env
PORT=5000
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret
```

Frontend `.env`

```env
VITE_API_URL=http://localhost:5000/api
```
